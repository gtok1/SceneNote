# 전체 추천 503 오류 수정 검증

사용자 요청: 검색 화면에 표시되는 추천 서버 503 오류 수정. 기존 22번 명세 D-4·D-5의 중복 제거, cursor, 부분 실패, 요청 상한을 유지한다.

## 원인과 수정

현재 달의 정상 TMDB 공급자를 모두 소비한 뒤 실패한 AniList만 미완료로 남아, 후속 요청이 AniList만 호출하고 ALL_PROVIDERS_FAILED 503으로 종료했다. 이전 달의 정상 추천으로 진행하지 못했다.

`recommendationCatalog.ts`에서 정상 공급자의 해당 월 탐색이 끝나면 이전 달로 진행한다. 실패와 완료 상태는 구분하며, 실패한 공급자는 정상 페이지가 남아 있는 동안 같은 월에서 반복 호출하지 않는다. 다음 달 탐색에서는 공급자를 다시 시도한다. 기존에 막힌 version 2 cursor도 처리한다. 실패 횟수는 cursor 검증 상한인 100으로 제한한다.

공급자 구성, 순위·취향 계산, 등록·노출·제외 작품 필터는 유지했다. 단일 공급자 또는 전체 공급자 장애는 여전히 재시도 가능한 오류다. 요청당 1개월·1라운드, 프론트 자동 탐색 횟수·시간 상한도 유지했다.

## 검증

- 전체 자동 테스트: 393/393 통과, 65 suites.
- TypeScript 검사, ESLint, Deno Edge Function 타입 검사, git diff --check 통과.
- 추가 회귀: 빈 현재 달+부분 장애에서 이전 달 추천, 이미 막힌 cursor 복구, 정상 공급자의 다음 페이지 처리 중 실패 공급자 반복 호출 방지, 애니 단독 장애 후 재시도 복구.
- 기존 부분 실패 테스트는 최소 탐색 월을 명시해 실제 정상 카탈로그 끝에서도 거짓 소진을 보고하지 않는지 검증한다.
- 실제 로그인된 Chrome의 기존 `/search` 오류 화면에서 다시 시도: **추천 작품 12개 표시**, 503 오류 제거, 일부 공급자 실패 안내 유지. 마지막 연속 응답은 7개·1개·4개, 모두 mediaType=all, failedSources=[anilist].
- 검증 과정에서 작품 등록·관심 없음 등 사용자 기록 버튼은 누르지 않았다. 정상 추천 노출에 따른 자동 impression 기록은 발생한다.

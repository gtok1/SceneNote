# SceneNote 7월 개선 로드맵 — Codex 작업 지시서 개요

작성일: 2026-07-07
대상: Codex (각 문서는 독립적으로 실행 가능한 작업 단위)

## 배경

SceneNote는 애니/드라마/영화 감상 기록 앱이며, 핵심 가치는 검색이 아니라
**사용자의 감상 기록과 타임라인 핀(Pin) 경험**이다.

현재 상태 점검 결과:
- 홈 화면(`app/(tabs)/index.tsx`)이 인기 추천 + 보는 중 목록 중심으로, 핵심 자산인 핀이 홈에 전혀 노출되지 않는다.
- 에피소드 진행 토글(`useToggleEpisodeProgress`)은 구현돼 있으나 카드 UI에 활용되지 않는다.
- 방영일(`air_date`) 데이터는 백필돼 있으나 검색 화면에서만 사용된다.
- 라이브러리 공유는 있으나 핀(장면) 단위 공유는 없다.
- 핀 탭 감정 통계 카드가 실제 감정 enum과 불일치한다.
- 회원 탈퇴가 미구현 상태다(스토어 심사 블로커).

## 공통 규칙 (모든 작업에 적용)

1. **RLS-first**: 사용자 데이터 테이블 접근은 RLS를 전제로 한다. 앱 레벨 보안만으로 처리하지 않는다.
2. **외부 API 키는 절대 클라이언트에 노출하지 않는다.** 외부 API 호출은 반드시 Supabase Edge Functions를 통한다.
3. **상태 관리 분리**: 서버 데이터는 TanStack Query v5, 로컬 UI 상태는 Zustand/Jotai.
4. **TypeScript strict 모드** 유지. 작업 완료 후 반드시 실행:
   - `npx tsc --noEmit`
   - `npx eslint .`
5. **긴 목록은 FlashList 우선**, FlatList는 fallback.
6. UI 문구는 한국어. 기존 톤(간결한 명사형 라벨)을 따른다.
7. 콘텐츠 메타데이터(외부 API)와 사용자 기록 데이터의 테이블 분리 원칙을 깨지 않는다.
8. 불확실한 외부 API 동작(예: 에피소드 캐시 없음)은 가정하지 말고 문서의 "주의사항"을 따르거나, 확실하지 않으면 결과 보고에 명시한다.

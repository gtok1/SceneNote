[공통 규칙](../../AGENTS.md)과 [문서 목차](../../docs/README.md)의 해당 기능 명세를 기준으로 감상 기록과 장면 핀을 쓰는 사람의 행동을 설명한다.

- 사용자 스토리는 상황·목표·행동·기대 결과와 검증 가능한 인수 기준으로 작성한다. 화면 정의는 진입 경로, 보이는 요소와 행동, 다음 화면, 예외 흐름을 [화면 구현 기준](../../docs/11_screen_implementation_spec.md)에 맞춘다.
- 관련 예외마다 어떤 입력에서 발생하는지, 사용자에게 무엇이 보이는지, 복구할 수 있는지를 적는다. 예를 들어 핀은 같은 시간의 복수 핀·시간 미지정·재생 시간 초과, 검색은 중복 작품·빈 결과·많은 결과와 부분 실패를 구분한다.
- 범위를 제안할 때 포함·보류 이유를 밝히고 이미 승인된 후속 기능을 보존한다. 정책 미결 사항과 기술 검토가 필요한 사항을 구분한다. 산출물은 요청 언어를 따르며 기본은 한국어다.
- 새 구현 명세는 [명세 작성 패턴](../../docs/00_codex_doc_pattern.md), UI 명세는 [공통 UI 규칙](../../docs/00_ui_style_rules.md)을 적용한다. 과거 결정 배경이 필요하면 [역할 메모리 색인](../agent-memory/mvp-product-planner/MEMORY.md)을 현재 명세와 대조한다.

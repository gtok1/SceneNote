# Codex 작업 요청: 핀 공유 카드 (장면 1개를 이미지로 공유)

## 배경

- SceneNote의 핵심 목적은 "내가 본 작품을 상대방과 소통·공유하는 수단"이다
  (00 개요의 제품 컨셉 참고). 그 첫 구현으로 라이브러리 목록 공유는 이미 있다
  (`src/services/libraryShare.ts`, `app/share/[id].tsx`,
  `supabase/functions/create-library-share`, `get-library-share`).
- 이 작업은 공유 수단을 **작품 목록 단위에 더해 장면 단위로 확장**한다.
  "이 작품 봤어?"(목록 공유)에 이어 "이 장면 봤어?"(핀 공유)까지 되면
  대화 소재의 해상도가 높아진다. 목록 공유를 대체하는 것이 아니라 보완한다.
- 핀 1개를 보기 좋은 카드 이미지로 만들어 OS 공유 시트로 내보내는 기능을 만든다.

## 목표

핀 상세 화면(`app/pins/[id].tsx`)에 "공유" 버튼을 추가하고, 탭하면
작품 제목 + 회차 + 타임코드 + 메모 + 감정이 담긴 카드 이미지를 생성해
기기 공유 시트(카카오톡, 인스타그램 스토리 등)로 공유할 수 있게 한다.

## 방식 결정 (중요)

**클라이언트 사이드 이미지 캡처 방식으로 구현한다.** 서버(Edge Function) 이미지
생성은 하지 않는다. 이유: MVP 복잡도 상한 원칙, 그리고 공유 링크/웹 페이지가
아니라 이미지 파일 공유가 목적이므로 서버 상태가 필요 없다.

- 사용 라이브러리:
  - `react-native-view-shot` — 카드 뷰를 이미지로 캡처
  - `expo-sharing` — OS 공유 시트 호출
  - 설치 전 `package.json`을 확인하고, 이미 있으면 재사용.
    설치는 `npx expo install`로 Expo SDK 호환 버전을 받는다.
- 웹 플랫폼: `expo-sharing`은 웹 지원이 제한적이다. 웹에서는
  `navigator.share` 가능 시 사용, 불가하면 이미지 다운로드로 대체한다.
  웹 대응이 과도하게 복잡해지면 웹에서는 버튼을 숨기고 결과 보고에 명시한다.

## 구현 지시

### 1. 공유 카드 컴포넌트

- 신규: `src/components/pins/PinShareCard.tsx`
- 고정 크기(권장 1080×1350 비율, 스토리/피드 겸용 4:5)로 오프스크린 렌더링
  가능한 순수 뷰 컴포넌트. props로 `TimelinePin`(`src/types/pins.ts`)을 받는다.
- 카드 구성:
  - 작품 제목 (필수)
  - 회차 라벨: `episode_number` 있으면 "N화"
  - 타임코드: `display_time_label` (예: 15:59) — 크게, 브랜드 컬러
  - 메모: 최대 4줄, 초과 시 ellipsis
  - 감정 뱃지: `emotion` 있으면 한국어 라벨 (`src/constants/emotions.ts`의
    `EMOTION_LABELS` 사용)
  - 하단에 앱 워드마크 "SceneNote"
- 스타일은 `src/constants/theme.ts`의 colors/spacing/radius를 사용한다.
- 포스터 이미지 포함 여부: 외부 API 포스터의 재배포 라이선스가 불확실하므로
  **1차 버전에서는 포스터를 넣지 않는다.** 텍스트 중심 + 배경 그라데이션/단색으로
  디자인한다. (TMDB 이미지 약관 검토는 후속 과제)

### 2. 스포일러 처리

- `is_spoiler === true`인 핀 공유 시:
  - 공유 전 확인 다이얼로그: "스포일러 핀입니다. 메모를 가린 카드로 공유할까요?"
    - 옵션 1 "가리고 공유": 메모 영역을 "🔒 스포일러 방지를 위해 가려진 메모"로 대체
    - 옵션 2 "그대로 공유": 메모 노출
    - 취소
- 스포일러가 아니면 다이얼로그 없이 바로 공유.

### 3. 진입점

- `app/pins/[id].tsx` (핀 상세)에 공유 버튼 추가. 기존 화면 액션 버튼들의
  스타일/배치를 따른다.
- 핀 탭(`app/(tabs)/pins.tsx`) 우측 상세 패널의 "핀 상세 열기" 버튼 근처에도
  같은 공유 액션을 추가한다 (동일 핸들러 재사용).

### 4. 캡처/공유 흐름

1. 공유 버튼 탭 → (스포일러면 다이얼로그) → 오프스크린 `PinShareCard` 렌더
2. `react-native-view-shot`의 `captureRef`로 PNG 캡처 (파일은 캐시 디렉터리)
3. `expo-sharing.shareAsync(uri)` 호출
4. 실패 시 사용자에게 한국어 에러 토스트/알림, 콘솔에 원인 로깅

## 범위 제외

- 공유용 웹 링크/딥링크 페이지 생성 (라이브러리 공유와 별개 과제)
- 포스터/스틸컷 이미지 포함
- 콘텐츠 단위(핀 여러 개) 타임라인 공유

## 수용 기준 (Acceptance Criteria)

1. 핀 상세에서 공유 버튼 탭 → OS 공유 시트가 열리고 카드 이미지가 첨부된다.
2. 카드에 작품명/회차/타임코드/메모/감정이 올바르게 렌더링된다.
3. 스포일러 핀은 확인 다이얼로그를 거치며, "가리고 공유" 선택 시 메모가 마스킹된다.
4. 메모가 없거나 감정이 없는 핀도 카드 레이아웃이 깨지지 않는다.
5. iOS/Android에서 동작. 웹은 다운로드 대체 또는 버튼 숨김(보고에 명시).
6. `npx tsc --noEmit`, `npx eslint .` 통과.

## 검증 방법

- 메모 있음/없음, 감정 있음/없음, 스포일러, 긴 제목(20자 이상), 긴 메모(200자)
  조합으로 캡처 이미지 확인.
- Android 에뮬레이터와 iOS 시뮬레이터(가능 시)에서 공유 시트 동작 확인.

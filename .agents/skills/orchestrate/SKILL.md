# SceneNote 산출물 통합 — Codex 진입점

이 저장소에는 Claude와 Codex용 진입점이 함께 있다. 동일 절차를 두 곳에서 관리하지 않도록 **[공통 통합 절차](../../../.claude/skills/orchestrate/SKILL.md)를 읽고 적용한다.** 해당 파일의 입력·기준 문서·실행 순서·출력 형식·완료 및 중단 조건을 사용한다.

- 필요한 입력은 요청 범위와 역할별 산출물이다. 없으면 공통 절차에 따라 누락을 표시한다.
- [AGENTS.md](../../../AGENTS.md)와 [문서 목차](../../../docs/README.md)의 해당 기능 명세를 따른다. 초기 MVP 범위를 후속 승인 기능 제거의 근거로 쓰지 않는다.
- 코드 구현·배포·일반 문서 감사에 이 스킬을 강제 적용하지 않는다.
- 공통 파일을 찾지 못하면 임의 절차를 만들지 말고 누락 경로를 보고한다.

절차 수정은 공통 파일에서 하고, 이 진입점은 사용 조건과 참조가 일치하는지 검증한다.
